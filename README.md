## 📖 About

This is my final project for **[The Unix Workbench](https://www.coursera.org/learn/unix)** (Johns Hopkins University, Coursera). I completed it in 2022 and revised it in 2026. The brief asked for:

* a Bash program that keeps asking the user to guess the number of files in a directory, saying whether each guess is too high or too low, until the guess is right
* a function, a loop and an `if` statement in that program
* a `makefile` that generates this README, including the date `make` was run and the number of lines in the script

The revised version also validates input, takes an optional directory argument, counts attempts, uses meaningful exit codes, and has an automated test suite that runs in CI.

## 🚀 Usage

```bash
git clone https://github.com/olaraym/Bash-Directory-Guessing-Game.git
cd Bash-Directory-Guessing-Game

./guessinggame.sh             # play in the current directory
./guessinggame.sh /some/path  # or in any other directory
```

| Exit code | Meaning |
|---|---|
| `0` | Correct guess |
| `1` | Input ended before a correct guess (e.g. Ctrl-D) |
| `2` | The argument is not a directory |

## 🛠️ Make targets

| Command | What it does |
|---|---|
| `make` | Rebuilds `README.md` from `README.template.md` with the current date and line count |
| `make test` | Runs the test suite in `tests/` |
| `make lint` | Checks every script with [ShellCheck](https://www.shellcheck.net/) |
| `make clean` | Removes the generated `README.md` |

## 🧠 Bash concepts used

| Concept | Where |
|---|---|
| Functions with `local` variables | `count_files`, `is_whole_number`, `main` |
| `while` loop with `read -r` and end-of-input handling | Main game loop |
| `if` / `elif` / `else` with arithmetic `(( ))` | Comparing the guess to the answer |
| Regex matching with `[[ =~ ]]` | Rejecting non-numeric input |
| `find` piped to `wc` | Counting regular, non-hidden files safely |
| Exit codes, `set -uo pipefail`, stderr | Error handling |
| Make dependencies and `sed` templating | Rebuilding the README when the script changes |
| Automated tests and GitHub Actions | `tests/test_guessinggame.sh`, `.github/workflows/ci.yml` |
